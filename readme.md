# YaCut - Сервис укорачивания ссылок

YaCut — это веб-сервис для создания коротких ссылок и асинхронной загрузки файлов на Яндекс Диск. Сервис позволяет преобразовывать длинные URL в короткие идентификаторы, а также загружать файлы на Яндекс Диск и получать короткие ссылки для их скачивания.

## Основные возможности

- **Генерация коротких ссылок**: Преобразование длинных URL в короткие идентификаторы
- **Пользовательские короткие ссылки**: Возможность указать свой вариант короткой ссылки
- **Автоматическая генерация**: Автоматическое создание уникальных коротких ссылок (6 символов)
- **Загрузка файлов**: Асинхронная загрузка файлов на Яндекс Диск с генерацией коротких ссылок
- **REST API**: API для программного доступа к функциональности сервиса
- **Редирект**: Автоматическое перенаправление на оригинальные ссылки

## Технологии

Проект построен на следующих технологиях:

- **Flask 3.0.2** — веб-фреймворк для Python
- **SQLAlchemy 2.0.21** — ORM для работы с базой данных
- **Flask-SQLAlchemy 3.1.1** — интеграция SQLAlchemy с Flask
- **Flask-Migrate 4.0.5** — миграции базы данных
- **Flask-WTF 1.2.1** — работа с формами и CSRF защита
- **aiohttp 3.10.5** — асинхронные HTTP-запросы для работы с API Яндекс Диска
- **SQLite** — база данных (для разработки)
- **Jinja2 3.1.4** — шаблонизатор
- **Bootstrap** — CSS-фреймворк для UI
- **WTForms 3.0.1** — валидация форм

## Локальный запуск проекта

### Предварительные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- Токен доступа к Яндекс Диску (опционально, для функции загрузки файлов)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd async-yacut
```

### Шаг 2: Создание виртуального окружения

Создайте и активируйте виртуальное окружение:

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
source venv/Scripts/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 4: Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующим содержимым:

```env
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key_here
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=your_yandex_disk_token_here
```

**Описание переменных:**
- `FLASK_APP` — имя приложения Flask
- `FLASK_ENV` — режим работы (development/production)
- `SECRET_KEY` — секретный ключ для сессий и CSRF защиты (сгенерируйте случайную строку)
- `DATABASE_URI` — URI подключения к базе данных
- `DISK_TOKEN` — токен OAuth для доступа к API Яндекс Диска (опционально)

**Как получить токен Яндекс Диска:**
1. Перейдите на https://oauth.yandex.ru/
2. Создайте приложение
3. Получите токен доступа

### Шаг 5: Инициализация базы данных

Если миграции еще не созданы:

```bash
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

Если миграции уже существуют:

```bash
flask db upgrade
```

### Шаг 6: Запуск приложения

```bash
flask run
```

Приложение будет доступно по адресу: `http://127.0.0.1:5000`

### Шаг 7: Проверка работы

Откройте в браузере:
- Главная страница: `http://127.0.0.1:5000/`
- Страница загрузки файлов: `http://127.0.0.1:5000/files`
- API эндпоинты: `http://127.0.0.1:5000/api/id/`

## API

### Создание короткой ссылки

**POST** `/api/id/`

```json
{
  "url": "https://example.com/very/long/url",
  "custom_id": "example"  // опционально
}
```

**Ответ:**
```json
{
  "url": "https://example.com/very/long/url",
  "short_link": "http://localhost/example"
}
```

### Получение оригинальной ссылки

**GET** `/api/id/<short_id>/`

**Ответ:**
```json
{
  "url": "https://example.com/very/long/url"
}
```

## Дополнительная информация

- Для работы загрузки файлов необходим валидный токен Яндекс Диска
- Автоматически генерируемые короткие ссылки имеют длину 6 символов
- Пользовательские короткие ссылки ограничены 16 символами
- Допустимые символы для коротких ссылок: латинские буквы (a-z, A-Z) и цифры (0-9)
